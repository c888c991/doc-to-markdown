# 文档转 Markdown

把 Word、PPT、Excel、PDF 这类办公文档，批量转换成干净的 Markdown，
方便直接丢给 AI 阅读、丢进知识库、或者用文本编辑器改。

底层基于微软开源的 [MarkItDown](https://github.com/microsoft/markitdown)，
外面包了一层批量处理和输出清洗。

## 这个工具解决什么

办公文档是二进制的，AI 没法直接读。转成 Markdown 之后：

- 体积小得多，同样的内容占用的上下文更少
- 标题、列表、表格的层级结构保留下来，AI 能分清哪是标题哪是正文
- 纯文本，可以 diff、可以版本管理、可以随便改

## 怎么用

### 方式一：双击（最省事，推荐）

1. 把要转换的文件复制到 **「待转换」** 文件夹里（可以直接放一整个子文件夹，会一起处理）
2. 双击 **「一键转换.bat」**
3. 等它跑完，结果在 **「转换结果」** 文件夹里，转换完窗口会自动帮你打开

### 方式二：拖拽

直接把文件（或文件夹）拖到 **「一键转换.bat」** 图标上，松手即可。

### 方式三：命令行

```bat
REM 处理「待转换」文件夹
.venv\Scripts\python.exe 转Markdown.py

REM 只转一个文件
.venv\Scripts\python.exe 转Markdown.py "D:\资料\合同.docx"

REM 转整个文件夹，并指定输出位置
.venv\Scripts\python.exe 转Markdown.py "D:\资料\合同" "D:\资料\合同md"
```

源目录如果是个文件夹，会连子文件夹一起递归处理，输出保持相同的目录结构。

## 支持的格式

| 格式 | 后缀 | 说明 |
| --- | --- | --- |
| Word | `.docx` | 标题、段落、表格、项目符号都能还原 |
| PowerPoint | `.pptx` | 按页切分，每页标题和正文都在 |
| Excel | `.xlsx` | 每个工作表转成一个表格 |
| PDF | `.pdf` | 文字版 PDF 效果好，扫描件需要 OCR |
| 网页 | `.html` `.htm` | |
| 电子书 | `.epub` | |
| 数据 | `.csv` `.json` `.xml` | |

**暂不支持的**：`.doc`、`.ppt`、`.xls`（都是十多年前的老格式）。
遇到这些，先用 Office 另存为新版格式即可 —— 脚本也会在运行时提示，不会默默漏掉。

## 转换后长什么样

转换结果会保留原文的结构，不是把文字揉成一团。一个带表格的 Word 会转成这样：

```markdown
# 2026 年第三季度经营分析

本报告汇总了第三季度的整体经营情况，数据截止 9 月 30 日。

## 一、核心指标

| 指标 | 本季度 | 同比 |
| --- | --- | --- |
| 营业收入 | 1,280 万元 | +18% |
| 净利润 | 215 万元 | +7% |
```

PPT 会按页切分，每页用 HTML 注释标出页码，方便定位原稿位置：

```markdown
<!-- Slide number: 3 -->
# 定价方案
| 档位 | 价格 | 交付内容 |
| --- | --- | --- |
| 引流款 | 9.9 元 | 单条脚本 |
```

## 关于输出清洗

MarkItDown 直接转 Word 表格时，会输出「一行空表头 + 分隔线 + 真实首行」，
结果是这样：

```markdown
|  |  |  |
| --- | --- | --- |
| 指标 | 本季度 | 同比 |
```

表头是空的，AI 读不出每一列代表什么。`转Markdown.py` 里的 `fix_empty_header()`
会检测这种模式，把真实首行提升为表头：

```markdown
| 指标 | 本季度 | 同比 |
| --- | --- | --- |
```

**这是走脚本、而不是直接敲 `markitdown` 命令的主要原因。**
（实测 PPTX 的表格不需要这个修复，DOCX 需要。）

注意：文档里的**图片不会变成文字描述**，只保留一个占位标记。
脚本负责把文字和表格抽干净；如果需要让 AI 看懂图里的内容，
要另外接图像识别模型。

## 目录结构

```
文档转Markdown\
├── 一键转换.bat          ← 双击这个
├── 转Markdown.py         ← 主程序
├── README.md             ← 本文件
├── 待转换\               ← 要转的文件丢这里
├── 转换结果\             ← 转好的 .md 在这里
└── .venv\                ← 独立的运行环境（不进版本库）
```

## 换机器时怎么重新搭

`.venv` 是程序的运行环境，不进版本库，删掉之后双击就报错。
在新机器上重建：

```bat
cd /d 文档转Markdown
python -m venv .venv
.venv\Scripts\python.exe -m pip install --index-url https://pypi.org/simple "markitdown[docx,pptx,xlsx,pdf]"
```

需要 Python 3.10 以上。**注意必须用 `--index-url` 指定官方源** ——
清华等国内镜像没有同步 `markitdown` 这个包，装了会报 `No matching distribution found`。

## 常见问题

**Q：转换结果和原来重名会怎样？**
A：直接覆盖旧的，重复运行不会堆出一堆重复文件。

**Q：能一次转很多个吗？**
A：能。全放进「待转换」，或者直接指向一个文件夹。

**Q：某个文件转换失败怎么办？**
A：窗口最后会列出失败的文件和原因。常见的是文件正被 Office 打开着（先关掉），
或者 PDF 是扫描件（需要 OCR，当前环境没装）。

**Q：为什么改了 `一键转换.bat` 之后中文乱码了？**
A：这个文件必须存成 **GBK（ANSI）编码**，并且**不能**加 `chcp 65001`。
用记事本另存为时选 ANSI 即可。
